# 👕 Conta Roupas

Um app simples e prático para gerenciar seu inventário de roupas!

## ✨ Funcionalidades

✅ Adicionar roupas (tipo, cor, tamanho, quantidade)
✅ Visualizar todas as suas roupas
✅ Buscar e filtrar por tipo, cor ou tamanho
✅ Ver estatísticas (total, tipos, cores)
✅ Deletar roupas
✅ Dados salvos automaticamente no seu navegador
✅ Design responsivo para celular, tablet e desktop

## 🚀 Como Usar

### 1️⃣ Abrir o App

**No GitHub:**
- Acesse: https://github.com/brunotc47-hub/conta-roupas
- Clique em `index.html`
- Clique em "Raw"
- Salve a página

**Ou acesse direto (recomendado):**
- https://brunotc47-hub.github.io/conta-roupas

### 2️⃣ Adicionar uma Roupa

1. Preencha o formulário:
   - Tipo (Camiseta, Calça, Vestido, etc)
   - Cor
   - Tamanho (PP, P, M, G, GG)
   - Quantidade

2. Clique em "➕ Adicionar"

### 3️⃣ Buscar Roupas

- Use a barra de busca para procurar por qualquer termo
- Resultados aparecem em tempo real

### 4️⃣ Deletar Roupas

- Clique no botão 🗑️ na roupa que quer remover

## 📊 Estatísticas

Veja em tempo real:
- Total de peças
- Quantos tipos diferentes
- Quantas cores diferentes

## 💾 Dados

Todos os seus dados são salvos **no seu navegador** usando localStorage. 
Nada é enviado para servidor!

## 🛠️ Tecnologias

- CSS3
- JavaScript Vanilla
- LocalStorage
